# triage-demo

Demo repository for showcasing CodeRabbit's Triage (PR Inbox) feature with PRs of varying severity/criticality.

A minimal Express app exposing a couple of user-lookup endpoints. Each pull request in this
repo intentionally introduces one issue of a specific severity so that CodeRabbit's review
findings feed realistic signals into Triage's priority scoring.

## Run

```bash
npm install
npm start
```
